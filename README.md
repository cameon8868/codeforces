# codeforces: решения на разных языках

Репозиторий для изучения возможностей разных языков программирования
на примере задач codeforces. Одна задача решается на нескольких языках,
чтобы сравнить синтаксис, стандартные библиотеки и подходы.

**Мой профиль codeforces:** [ggca](https://codeforces.com/profile/ggca)

## Как устроена папка с задачей

Каждая задача лежит в папке `НазваниеЗадачи` и содержит:

- `НазваниеЗадачи.md` с условием, идеей решения и оценкой сложности
- файлы решений на разных языках
